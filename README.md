# 梅花幼儿园复盘部 · 桌面版（CS2 复盘终端）

把 `cs2-tactics` 这个纯静态站包成一个**双击就能开的电脑应用**：无地址栏、无标签页，
启动时先播一段开机动画，然后落在**主页**（不是直接甩进战报页）。

- 站点本体不在这里，而是在 `J:\工作空间\cs2-tactics`（开发时直接读那个目录）
- 这里只有三层：**主进程**（起本地服务 + 两个窗口）、**开场动画**（splash.html）、**打包脚本**

---

## 〇、桌面上那个图标

安装版装完会在**桌面**和**开始菜单**各建一个「CS2复盘终端」快捷方式，双击就开，不需要命令行。

- 装在哪：`%LOCALAPPDATA%\Programs\cs2-replay-terminal\`
- 卸载：那个目录里的 `Uninstall CS2复盘终端.exe`，或 设置 → 应用 → CS2复盘终端
- 装的是**快照**：站点内容在打包那一刻就固定了。想让它读实时站点（改站的时候特别有用）：

  ```bat
  set CS2_SITE=J://工作空间//cs2-tactics
  "C://Users//<你>//AppData//Local//Programs//cs2-replay-terminal//CS2复盘终端.exe"
  ```

  这个环境变量优先级最高（见 `resolveSiteRoot`）。
- 版本升级：拿到新安装包直接装，会覆盖并保留快捷键 / 窗口位置

## 一、跑起来

**最省事：双击 `dist\CS2复盘终端-1.0.0-安装版.exe`**，装完桌面上就有「CS2复盘终端」，
以后双击图标就开 —— 没有黑窗口、没有地址栏，跟正常软件一样。
不想安装就用 `dist\CS2复盘终端-1.0.0-便携版.exe`（单个 exe，双击直接跑）。

开发/改代码时用 `启动.bat`（第一次会自动 `npm install`）。

命令行：

```bash
cd J:\工作空间\cs2-desktop
npm install        # 只装 electron / electron-builder，约 200MB
npm start          # 黑屏动画 → 主窗口
```

想单独看一眼开场动画 / 主窗口长什么样（截完图自动退出，不留在屏幕上）：

```bash
npx electron . --shot      # 输出 shot-splash.png、shot-main.png
```

首次 `npm install` 会下载 Electron 运行时（约 100MB），装一次就行。

想指向别的站点目录：

```bash
set CS2_SITE=D:\somewhere\cs2-tactics
npm start
```

## 二、启动动画（`splash.html`）

三段式，对应你给的两段视频：

| 段 | 时间 | 画面 | 参考 |
|---|---|---|---|
| ① 品牌 | 0 ~ 1.9s | 纯黑 + 白色「梅」圆标（外圈一段橙色弧缓慢旋转）+ 中英双行名，一束斜光扫过，四角等宽字标注 | 视频1 开头（黑底白 logo） |
| ② 启动 | **由真实进度决定** | 标志缩小上移，细线进度条 + 等宽字状态 —— **每一格都是主进程真的做完了一件事**（服务就绪 18% → 开始加载 32% → DOM 解析 56% → 资源完成 74% → 首屏绘制 90% → 就绪 100%）。本地站通常 1 秒内走完，所以整段开机 ≈ 2.5s | 原来那套 + 用户「做成确实是在启动中的」 |
| ③ 显影 | 3.4 ~ 4.8s | 标志位置拉出一条细光 → 拉满屏宽 → 升到顶栏下沿 → 顶栏被它「拉下来」（`scaleY` 0.02→1）→ 图标/导航逐个亮起 + 一道高光扫过 → 两块毛玻璃面板带着 blur 从下方浮起 | 视频2 的「渐变型产生内容」 |

这一版的显影是**有因果的**：那根细光是从「梅」标志的位置长出来的，一路长成顶栏下沿，
顶栏再从这条线往下展开 —— 开机画面和主界面之间是同一个动作在延续，不是换了一页。

最后一帧不是黑屏，而是**近似主页的骨架**：主进程这时把 splash 窗口的 opacity 从 1 淡到 0
（真界面已经在下面渲染好了），所以看起来是「同一块屏由虚到实」，不是硬切窗口。

- 窗口尺寸：splash 用的是主窗口**内容区**的 `getContentBounds()`，位置和大小完全一致，
  淡出时零位移（标题栏是主窗口自己的，所以开机动画看起来就是「应用窗口里的画面」）
- 节奏/文案集中在 `splash.html` 底部的 `STEPS` 数组，③ 的时点由 `reveal()` 决定
- **点击/按键可跳过**，主进程还有 6 秒兜底（收不到 `boot:done` 就强制放行）
- 进度条有一个 **520ms 的最短展示时间**：页面几百毫秒就 ready 时，不至于只闪一下
- 等页面的时候（40%~99%）条子上会跑一层流光，不会看着像卡死
- **任务栏进度**：同一套百分比还会通过 `win.setProgressBar()` 画在**任务栏的应用图标上**
  —— 就是下载文件时任务栏按钮底下那条进度，切到别的窗口也能看到它在走
- 颜色：`--accent` 橙 `#ff9f1a`，和站点同一套语言

## 二·二、设置面板与检查更新

主窗口里注入了**一个齿轮按钮 + 一个玻璃面板**（`preload.js` 里注入，只在桌面版出现，
网页版没有）—— 这就是「设置按钮」的最小形态，四项：

| 项 | 做什么 |
|---|---|
| 检查更新 | 主进程用 `https` 拉 `https://xiaochun-benzi.pages.dev/cs2/app/latest.json`，比版本号；有新版在齿轮上点个橙点，面板里给下载链接（`shell.openExternal`）。开机 6 秒后还会静默查一次 |
| 切换日夜主题 | 直接复用站点的 `#togTheme`（连 View Transitions 那套过渡一起继承） |
| 打开日志文件夹 | `shell.showItemInFolder(启动日志.txt)` |
| 关于 | 版本号 + 快捷键 |

**为什么检查更新走主进程而不是页面 `fetch`**：页面 origin 是 `127.0.0.1:随机端口`，
去拉 `pages.dev` 是跨域，`latest.json` 没带 CORS 头就会被拦。主进程用 Node 的 https
既没有 CORS 也没有缓存策略问题。

**发版流程**（改版本 → 出包 → 上线 → 用户点检查更新）：

1. `package.json` 的 `version` 改掉 → `npm run sync` → 打包
2. 把新包放到能直链的地方，改站点上的 `app/latest.json`：
   ```json
   { "version": "1.0.1", "date": "2026-11-02", "size": "76.1 MB",
     "file": "CS2复盘终端-1.0.1-安装版.exe",
     "sha256": "…", "url": "https://…/CS2复盘终端-1.0.1-安装版.exe",
     "portable": "https://…/便携版.exe",
     "notes": ["本次更新了什么"] }
   ```
3. 部署站点。之后老版本点「检查更新」就会看到橙点和链接。

> ⚠️ `app/latest.json` 必须能被公网访问 —— 它就是版本号的唯一真相来源。
> 站点上的 `download.html` 读的也是同一个文件，一处改两边同步。

## 二·五、界面上的几处「质感」约定

| 东西 | 做法 | 位置 |
|---|---|---|
| 顶栏毛玻璃 | `rgba(.62)` + `backdrop-filter: blur(18px) saturate(1.45)` + 内侧高光；滚过 8px 加 `body.scrolled` 自动加深并落影 | `style.css` + `glass.js` |
| 卡片跟随鼠标的柔光 | `pointermove` 只记坐标，`rAF` 里写 `--mx/--my`，CSS 用 `radial-gradient(at var(--mx) var(--my))`；**触屏设备自动关掉**。作用在 `.card / .tac-card / .pro-card / .feat-card / .fn-cell` | `style.css` + `glass.js` |
| 长卷目录 / 选手下拉 | 玻璃浮层：`.42/.55` 底 + `blur(20~22px) saturate(1.5)` + 内侧高光 + 落影 + 入场位移（`glassIn` / `menuIn`） | `demo.css` 末尾 |
| 回合记录「磁吸高亮」 | 列表里**只有一条**高亮带，指针扫到哪行就 160ms 缓动滑过去（不是逐行闪烁，所以有「被吸走」的感觉） | `demo/index.html` + `demo.css` |
| 卡片入场「呼吸」 | 别人按 DOM 序号 `%6` 错峰（会错拍），这里按**视觉行**分组、行内从左到右 65ms 递增，落位带 0.985→1 的轻微缩放 | `reveal.js` + `style.css` |

> ⚠️ `.map-card` / `.stat-card` 的 `::after` 另有用途（地图悬停浮层 / 统计角标），
> 光斑不要扩到它们身上。

## 三、打包成 .exe

```bash
npm run sync                  # 把静态站拷进 site/（只拷 assets/demo/两个 html，约 24MB）
npx electron-builder --win --config.win.signAndEditExecutable=false
```

产出在 `dist/`：

| 文件 | 用途 |
|---|---|
| `CS2复盘终端-1.0.0-安装版.exe` | NSIS 安装包，装到用户目录、自动建桌面 + 开始菜单快捷方式 |
| `CS2复盘终端-1.0.0-便携版.exe` | 单文件免安装，双击即用（每次启动会解压到临时目录，慢 1~2 秒） |
| `win-unpacked/` | 免安装目录版，调试最快 |

> ⚠️ `--config.win.signAndEditExecutable=false` 是这台机器上的**必需参数**：
> electron-builder 要解压 `winCodeSign` 缓存（里面有 macOS 的 .dylib 符号链接），
> 当前账户没有创建符号链接的权限，不加这个参数会一直卡在解包失败。
> 代价：`win-unpacked` 里那个 exe 的文件图标还是 Electron 默认图标
> （窗口图标 / 任务栏图标 / 安装包图标都是我们自己的「梅」，不受影响）。

## 五、实现要点（改之前先看）

1. **必须起本地 HTTP 服务**，不能 `loadFile()`。战报页大量 `fetch()` 读 JSON，
   `file://` 下会被 CORS 拦死，整页空白。所以主进程用 `http.createServer` 监听
   `127.0.0.1:0`（系统随机空闲端口），主窗口加载 `http://127.0.0.1:<port>/demo/index.html`。
2. **窗口的显示时机由两件事共同决定**：splash 动画播完（IPC `boot:done`）**且**
   主窗口 `did-finish-load`。少等任何一个都会出现「白屏闪一下」或「动画卡住」。
3. **单实例锁**：重复双击只聚焦已有窗口，不会起第二份服务。
4. **站外链接丢给系统浏览器**（`setWindowOpenHandler`），不在应用里开新窗。
5. 快捷键：`F12` 开发者工具、`F5` / `Ctrl+R` 刷新（本地调试用）。

## 七、打不开 / 启动失败怎么办

按顺序查三样，基本都能定位：

1. **看 `启动日志.txt`**（就在本目录，每次启动会重写）。
   它记的是主进程走到了哪一步：`splash 窗口已创建` → `主窗口开始加载` →
   `页面加载完成` → `收到 boot:done` → `主窗口已显示`。
   停在哪一步，问题就在那一步。

2. **`启动.bat` 会自己报错**：它会等 12 秒，进程还在就算成功；
   一个进程都没有就把日志打屏并 `pause` 停住，不会一闪而过。

3. **GPU 崩了会自动降级**：显卡驱动 / 远程桌面 / 虚拟机上，Chromium 的 GPU 进程
   可能一起来就崩（日志里是 `子进程退出 type=GPU reason=crashed`），
   这时程序会**自动改成软件渲染重启一次**，并把「这台机器要用软件渲染」记在
   `%APPDATA%\梅花幼儿园复盘部\boot-state.json`，以后直接走软件渲染。
   想恢复硬件渲染：删掉那个 `boot-state.json` 即可。

### 两个已经踩过的坑（改脚本前必读）

- **`.bat` 必须是 CRLF 换行**。我第一版是用编辑器写的，LF 换行 —— Windows 的 cmd
  按字节逐行解析，遇到 `if (...)` 这种带括号的块会直接错位，报一堆
  `'xxx' 不是内部或外部命令`，然后**静默退出**（窗口闪一下就没了）。
  以后改 `启动.bat` 用记事本/VS Code 保存成 CRLF，别用会写 LF 的工具。
- **`start "" "%EXE%" "%~dp0"` 里的路径要写成 `"%~dp0."`**。`%~dp0` 末尾自带反斜杠，
  紧跟一个双引号会被当成转义，Electron 收到的路径就是坏的。
- 如果是从 IDE / 某些终端里调起来，先 `set ELECTRON_RUN_AS_NODE=`，
  否则 Electron 会以纯 Node 模式运行，`require('electron')` 拿不到 `app`。
